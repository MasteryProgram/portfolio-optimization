# Portfolio Optimization

This repository contains a structured implementation of a financial time series forecasting and portfolio optimization challenge using Python.

## Contents

- `src/`: Reusable helper modules for data ingestion, exploratory analysis, and forecasting models.
- `notebooks/`: Jupyter notebooks for Task 1 (EDA) and Task 2 (model development).
- `data/processed/`: Processed data artifacts generated from the source.

## Setup

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Workflow

- `task-1` branch: Data extraction, cleaning, EDA, and stationarity analysis.
- `task-2` branch: Time series forecasting with ARIMA and LSTM models.
